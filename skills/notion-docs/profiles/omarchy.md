# Profile: omarchy

## Destination

```
Dashboard → Omarchy   (id cached as `omarchy` in notion-ids.json)
```

Flat: one page per fix/customisation directly under Omarchy, next to
"Keybindings configs" and "Discord fucking update fix". No sub-hierarchy.

Covers desktop customisation and system patches: Hyprland, omarchy-bar
plugins, terminal config, Spicetify, anything in `~/.config/omarchy/patches/`.

## Page title

What it fixes or customises, in plain words — e.g. "Spotify retro82 theme
(Spicetify) — survives updates". These are notes to a future self who has
forgotten everything, so the title should say what problem to look for.

## Required sections

1. **What it is** — what was customised and why that route (usually: there is
   no config option, so a patch is needed).
2. **Why it keeps breaking** — what resets it (package update, Omarchy update).
3. **The fix** — the exact command(s). One code block, run-as-is.
4. **How to check** — commands that show whether it is applied right now.
5. **Files** — every script/config involved, with a one-line purpose.
6. **Things that are easy to miss** — the gotchas that cost time the first time.
7. **To-do** — checklist, if anything is pending.

Plain end of the scale: no diagram, no cover, no ToC.
